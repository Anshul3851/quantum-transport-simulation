# Project instructions

- This is a computational physics research project.
- Physics and numerical correctness come before convenience.
- Scientific code should remain simple and readable.
- Avoid unnecessary classes and abstractions.
- Numerical conventions and physical sign conventions must be documented.
- Do not fabricate numerical results.
- Scientific changes must have validation tests.
- Do not claim a calculation is validated unless the relevant test or numerical check has actually been run.
- Keep the project reproducible.
